# Sample image provenance

These two images were generated specifically for the CDE2 public sample with OpenAI image generation on 2026-08-15. No source images were supplied, and the prompts requested no readable text, logos, brands, watermarks, copyrighted interfaces, or recognizable real people.

- `creator-workstation.webp`: a generic non-engineer creator refining a vertical video at a home desk, photographed from behind with warm lamp light and cool monitor light.
- `storyboard-desk.webp`: generic hands arranging abstract, unlabeled storyboard cards and color swatches on a dark creative desk.

The generated PNG outputs were resized and converted to WebP for the repository. They are used only as replaceable sample media and are included with the project.
