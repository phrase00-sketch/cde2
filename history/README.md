# CDE1 history

`cde1-scene-editor-v19.html` is the final archived build of the predecessor that led to CDE2.

It is included to make the project's evolution inspectable: the tool began as a smaller scene editor, grew through repeated production use, and was eventually redesigned as CDE2. This historical file is not supported and may expect an optional local renderer service on `127.0.0.1:3737` for some export operations.

Use the repository-root `index.html` for current work.
